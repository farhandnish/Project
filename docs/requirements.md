# Requirements

## Functional requirements (what the system must DO)
* **FR1:** The system shall display a categorized catalog of digital game top-ups.
* **FR2:** The system shall require the customer to input a valid game ID before checkout.
* **FR3:** The system shall allow store administrators to update product prices from a dashboard.

## Non-functional requirements (how the system must PERFORM)
* **NFR1:** The storefront interface shall load within 2 seconds to ensure a smooth browsing experience.
* **NFR2:** The checkout process shall securely encrypt all customer session data.
