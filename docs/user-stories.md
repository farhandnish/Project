# User Stories

Format: As a [type of user], I want [goal], so that [reason or benefit].

1. As a customer, I want to browse available digital game top-ups, so that I can easily find the premium currency for my specific game. (Supports FR1)
   * **Acceptance Criterion 1:** The system displays a catalog of available games (e.g., Valorant, Mobile Legends) with their respective top-up denominations and prices.
   * **Acceptance Criterion 2:** Customers can filter the catalog by category (e.g., PC Games, Mobile Games, Prepaid Internet).

2. As a customer, I want to securely enter my game ID during checkout, so that the top-up is credited to the correct account. (Supports FR2)
   * **Acceptance Criterion 1:** The checkout page includes a mandatory input field for the specific user ID or game account number.
   * **Acceptance Criterion 2:** The system displays a confirmation prompt asking the user to double-check their ID before finalizing the payment.

3. As a store admin, I want to update the prices of prepaid internet packages, so that I can adjust to changing supplier costs. (Supports FR3)
   * **Acceptance Criterion 1:** The admin dashboard features an "Edit Product" button next to each listed item in the database.
   * **Acceptance Criterion 2:** Any price changes saved by the admin are reflected immediately on the customer-facing storefront.
